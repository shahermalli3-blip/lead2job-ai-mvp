# Lead2Job mobile packaging

Lead2Job is prepared as an installable PWA first. The next native-store packaging step should wrap the production app for Android and iOS without duplicating the product backend.

## Production app
https://lead2job-ai-mvp.vercel.app/start.html

## Package identity (provisional until final brand name is approved)
- App name: Lead2Job
- Suggested application id: app.lead2job.mobile
- Web app start path: /start.html
- Display: standalone
